Almanac mockup · demo data

What grew, what shipped, and what changed in the soil, Jul 3 → Oct 1, with what is happening now at the right edge.

Plants. One plant per week. Height = runs that week (√ scale, same for every row). Bloom fill = success share (partial = ½, unknown excluded); hollow bud when fewer than 5 labeled runs.
Seasons. Dashed rule = harness change (a new season): commit subject on top, before → after per agent. ◆ = 95% intervals separate, ≈ = within noise. Correlation, not causation.
Soil. Band = tokens loaded in every session (CLAUDE.md chain, imports, MEMORY.md, listings). Same scale for all beds.
Irrigation. Water line = loop-triggered runs (one tick each, red = failed). Pools = flooding day; broken brown line = dry (no run for 3× the cadence); dotted = configured, runs not recorded.
Harvest. Shipped = runs that committed, pushed, or opened a PR. Solid = verified (tests passed after the last edit), outline = unverified.
Now. Now = what each agent is doing at this moment. Ring = context fill; amber tag = waiting on you (dashed when inferred).
